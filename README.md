## ✦ WHY A GIT-GIT-HUB WITNESS

A git commit hash is **tamper-evident**: any later modification to the notice
file produces a different hash, leaving the original provably intact. Combined
with an annotated tag and a GitHub Release (both stamped by GitHub's
server-side clocks), this gives independent, verifiable proof of existence and
priority date — no notary, no registration fee, no third party required.

**Verify for yourself:**

```bash
git clone https://github.com/[username]/[repository].git
cd [repository]
git show trademark-christopher-david-ayotte-v1.0
```

The hash, timestamp, and file contents reproduce the instrument exactly. The
original notice remains independently provable forever; its priority date is
fixed at first push.
